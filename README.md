# Clock and Alarm
This is a web app which shows analog clock model, and it also allows users to set alarm.

## Features
- Interactive and responsive interface
- Exact analog clock model
- Alarm support with audio
- Hour, minute, second and alarm hands

## Technology Used
- HTML5
- CSS3
- Java Script

## How to Run
1. Clone this repository
    ```bash
    git clone https://github.com/603codes/Clock
    ```
2. Open project
3. Open `index.html` in your browser
